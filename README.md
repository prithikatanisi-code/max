# BEYOND — Intelligent Tourism Network

A GitHub-ready tourism intelligence prototype.

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Deploy
Build with `npm run build`. The generated `dist` folder can be deployed using GitHub Pages.

## Important
Crowd figures and tourism-board analytics are DEMO DATA. The architecture is intended to connect authorized real-time APIs later.
